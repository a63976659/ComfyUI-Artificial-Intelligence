# 💬 ComfyUI-Artificial-Intelligence (本地大模型智能助手)

**将强大的本地大语言模型（LLM）无缝集成到您的 ComfyUI 工作流中。无需 API Key，保护隐私，开箱即用。**
- [![Bilibili](https://img.shields.io/badge/bilibili-猪的飞行梦-00A1D6?logo=bilibili&logoColor=white)](https://space.bilibili.com/2114638644)
## ✨ 核心优势

* **🚀 零门槛，自动部署**：内置国内镜像加速下载，只需选择模型，系统自动拉取。
* **🔒 100% 本地运行**：完全在本地显卡运行，保护隐私，无 API 费用。
* **🇨🇳 全中文友好界面**：参数、选项全汉化，专为中文用户优化。
* **🧠 支持前沿模型**：支持 **Qwen 2.5 / Qwen 3** 文本大模型、**Qwen3 语音系列**（合成/克隆/识别）、**Gemma 4** 多模态大模型，以及 **腾讯 Hunyuan-MT / 字节 Seed-X** 专用翻译大模型。
* **🧩 多环境隔离运行**：不同模型所需的依赖版本相互冲突时，各节点在独立虚拟环境的子进程中运行，互不干扰，用完即释放显存。
* **🎛️ 精细控制**：支持随机种子、温度、Top_P 等专业参数调节。

## 🧩 节点功能介绍

该插件位于节点菜单的 **Category: 💬 AI人工智能** 下，并按 **千问系列 / 谷歌系列 / 实时翻译 / 加载音频 / 加载视频** 子分类归类。

### 1. 🧠 LLM 智能翻译

* **用途**：提示词润色、多语言互译（中/英/日/韩等）。
* **特点**：比翻译软件更懂 Stable Diffusion 的语境。

### 2. 💬 LLM 智能对话

* **用途**：创意文案生成、角色扮演、逻辑推理。
* **特点**：支持 System Prompt（人设指令）和 Seed（随机种子）锁定，方便复现结果。

### 3. 🔊 Qwen 语音合成 (CustomVoice)

* **用途**：基于官方微调的 9 位高质量预设角色（如 Vivian、Uncle_Fu）进行语音生成，适合稳定商用。
* **特点**：**稳定性极高**，支持**情感指令控制**（如输入“用愤怒咆哮的语气”），支持多语言混合生成。

### 4. 🔊 Qwen 语音设计 (VoiceDesign)

* **用途**：无需参考音频，通过自然语言描述（Prompt）凭空创造独一无二的声音。
* **特点**：真正的**“文本捏音”**，可自定义性别、年龄、音色和语气（如描述“一个稚嫩的五岁女孩，声音尖细且在撒娇”）。

### 5. 🔊 Qwen 语音克隆 (VoiceClone)

* **用途**：输入 5-10 秒参考音频，即可零样本复刻任意人物的声音。
* **特点**：支持**标准模式**（高还原度，需输入参考文本）和**极速模式**（仅提取音色），支持**批次输出**和精细化声学参数控制。

### 6. 🎤 Qwen 语音识别 (ASR) / 批量语音识别

* **用途**：将语音转写为文字，支持中英日韩等多语言，可选输出**带时间戳**的分段文本。批量节点可对音频列表逐条识别。
* **特点**：时间戳按**标点、静音间隔、段长**三重规则智能断句，前奏/间奏/停顿处自动分段，时间点贴合真实发声区间；模型与 TTS 共用 `models/TTS` 目录。

### 7. 🖼️🎧🎬💬 Gemma 4 多模态系列

* **图像理解**：反推 SD/Flux 英文提示词、中文详细描述、OCR 文字提取、自定义提问。
* **多模态对话**：可选接入图像/音频一起提问，支持思考模式。
* **音频理解**：语音转写、翻译成中文、音频内容描述。
* **视频理解**：接「加载视频」的图像序列，均匀抽帧后理解视频内容，可选同时接入音频。
* **特点**：因 Gemma 4 需要更高版本 transformers，全部在独立虚拟环境的**隔离子进程**中运行，对其它节点零影响，运行后可立即卸载释放显存。

### 8. 🌐 实时翻译 (Hunyuan/Seed-X/Qwen)

* **用途**：语音多语种翻译，翻译过程在节点显示区**打字机式实时刷新**，像流式对话一样动态显示当前输出内容，输出口给出完整译文。
* **支持三家国产模型**：腾讯 **Hunyuan-MT-7B**（WMT25 国际翻译大赛 31 个语向拿下 30 个第一，推荐）、字节 **Seed-X-PPO-7B**、阿里 **Qwen 2.5/3** 系列，下拉列表限定兼容型号，防止选错无效。
* **专做语音翻译**：节点上没有文本输入框，请把音频接到“音频”输入（如 🎙️ 麦克风录音节点），内部先经 Qwen3-ASR 识别再翻译，实现“说话 → 译文”一条龙。
* **真·实时同传**：麦克风录音节点连上本节点后，点录音节点上的“🌐 开始实时翻译”按钮，**无需点击运行**，边说边自动断句，译文逐句持续显示在本节点上。

### 9. 🎙️ 麦克风录音 (Recorder)

* **用途**：点击节点上的“开始录音”按钮采集麦克风声音（需浏览器授权），停止后自动上传并填入文件名，输出 AUDIO。
* **特点**：可直接连接实时翻译节点的音频输入，也可连接语音识别、语音克隆等任意接收 AUDIO 的节点；需通过 localhost 或 HTTPS 访问 ComfyUI（浏览器麦克风安全策略）。
* **🌐 开始实时翻译**：需先把音频输出连到实时翻译节点（未连接时点击会提示），点击后进入真·实时模式——持续采集麦克风 + 能量 VAD 自动断句（静音 0.7 秒断句、短杂音自动丢弃、尾部静音自动裁剪），逐句上传识别翻译，再次点击停止并按开关释放显存。

### 10. 📝 持续填充文本 (Text Accumulator)

* **用途**：多行文本框**直接显示在节点上**，作为译文/文本的持续汇总区，每次新增内容自动换行追加。
* **用法**：把 `🌐 实时翻译` 的“翻译结果”连到本节点的“追加文本”输入即可——真·实时模式下每翻译完一句自动追加一行，无需点击运行；一次性图执行模式下点运行也会追加一行。
* **特点**：文本框可手动编辑、复制或全选删除清空；内容随工作流一起保存，刷新页面或重启 ComfyUI 都不会丢失。

## 💻 安装方法 (Installation)

### 方式一：通过 GitHub 安装 (推荐)

1. 打开您的 ComfyUI 目录，进入 `custom_nodes` 文件夹。
2. 在地址栏输入 `cmd` 或右键打开终端/命令行。
3. 输入以下命令克隆本项目：
```bash
git clone https://github.com/a63976659/ComfyUI-Artificial-Intelligence.git

```


4. 进入插件文件夹并安装依赖（秋叶启动器无需执行这一步）：
```bash
cd ComfyUI-Artificial-Intelligence
pip install -r requirements.txt

```


5. 重启 ComfyUI。

## 📥 模型下载与管理

1. 本插件的翻译和对话模型存放目录为：`ComfyUI/models/LLM`
2. 本插件的语音模型模型存放目录为：`ComfyUI/models/TTS`

### 方法 A：自动下载 (最简单)

1. 在节点界面中，将 **"自动下载模型"** 开关设置为 `True`。
2. 在 **"模型名称"** 列表中选择您想要的模型（例如 `Qwen2.5-7B-Instruct`）。
3. 运行工作流（Queue Prompt）。
4. 插件会自动检测本地是否存在该模型，若不存在，将通过国内镜像源自动下载并保存到 `models/LLM` 或`models/TTS` 目录中。
* *注意：首次下载可能需要一定时间，请关注控制台（Console）进度。*



### 方法 B：手动下载 (适用于网络受限环境)

如果您希望手动管理模型，请按照以下步骤操作：

1. **访问模型库**：前往 HuggingFace 或 ModelScope 下载模型文件。
* [Qwen2.5-7B-Instruct](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct)
* [Qwen2.5-3B-Instruct](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct)
* [Qwen3-4B-Instruct](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct) *(注：请查找对应的Qwen仓库)*
* [Hunyuan-MT-7B](https://huggingface.co/tencent/Hunyuan-MT-7B) *(实时翻译节点推荐)*
* [Seed-X-PPO-7B](https://huggingface.co/ByteDance-Seed/Seed-X-PPO-7B)


2. **创建文件夹**：
在 `ComfyUI/models/LLM` 目录下创建一个与模型名称完全一致的文件夹。例如：
* `ComfyUI/models/LLM/Qwen2.5-7B-Instruct`


3. **放入文件**：
将下载的所有模型文件（`.safetensors`, `config.json`, `tokenizer.json` 等）放入上述文件夹中。
4. **目录结构示例**：
确保您的文件结构如下所示：
```text
ComfyUI/
├── models/
│   ├── LLM/
│   │   ├── Qwen2.5-7B-Instruct/
│   │   │   ├── model-00001-of-00004.safetensors
│   │   │   ├── config.json
│   │   │   ├── tokenizer.json
│   │   │   └── ... (其他文件)

```


5. **刷新 ComfyUI**：下载完成后， ComfyUI 界面,点击键盘刷新按钮的 "R" ，或重启 ComfyUI。

* *或者：直接将解压后的所有文件复制到 ComfyUI 整合包的 `python_embeded/` 根目录下。*
